# 進度看板

Chief 是唯一能修改這個檔案的角色。Chief 每次開始工作時先讀這個檔案，不依賴對話紀錄。

狀態：`todo` → `building` → `verifying` → `fixing` → `passed` → `merged`，或 `escalated`（已開 issue 等 Kuei）、`blocked`（依賴的 ticket 尚未完成或被擋住）。
