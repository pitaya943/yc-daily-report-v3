# T-003 共用基礎：結果類別、稽核寫入、權限檢查

## 目標

見完成條件。這張 ticket 不對應 spec 的 scenario，以檢查清單驗收。

## 要讀的檔案

只讀這些，不要載入其他 feature 檔。

- `AGENTS.md`
- `spec/README.md`（寫作規約、結果類別）
- `spec/glossary.md`

## 完成條件

1. 七個結果類別對應到 `spec/README.md` 的 HTTP status，並回傳完整的錯誤字串。
2. `audit.write(actor, type, description)` 可用；類型限於 `spec/appendix-c-audit-types.md`。
3. 權限檢查以角色、擁有權、狀態為輸入；被拒絕時自動寫 `ACCESS_DENIED`。
4. 共用步驟可用：`the request is rejected as <OUTCOME> with message "<訊息>"`、`nothing is written`、`an audit row "<type>" is written with actor "<name>"`。
5. 「nothing is written」以比對動作前後的資料庫內容實作，不是只檢查回應。
6. CI 全綠。
7. 每一條完成條件都附上證據：CLI 輸出貼在 PR 說明；有畫面的功能附截圖，存在 `docs/evidence/T-003/`。
8. PR 說明依 `.github/PULL_REQUEST_TEMPLATE.md` 填寫。
